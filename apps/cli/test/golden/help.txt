$ maruhi schema --help
DESCRIPTION
  Show the environment's declared variable schema (names, types, required, status, descriptions; no values). Bare `maruhi schema` shows; `schema set` writes

USAGE
  maruhi schema [subcommand] [flags]

FLAGS
  --server string     Server URL (defaults to config server)
  --project string    Project ID (default: the `defaultProject` setting)
  --env string        Environment ID (default: the `defaultEnvironment` setting)

GLOBAL FLAGS
  --help, -h       Show help information
  --version, -v    Show version information

SUBCOMMANDS
  set                Set a variable's schema fields (type / required / description) as a partial update. A missing name is created as a declared variable without a value. A declaration cannot be deleted from the CLI yet; downgrade a mistaken one with --optional so `maruhi run` proceeds
  import             Import schema candidates from a .env or .env.example file with interactive per-variable approval (declares names without sending values; optionally pushes a value per variable)

$ maruhi schema set --help
DESCRIPTION
  Set a variable's schema fields (type / required / description) as a partial update. A missing name is created as a declared variable without a value. A declaration cannot be deleted from the CLI yet; downgrade a mistaken one with --optional so `maruhi run` proceeds

USAGE
  maruhi schema set [flags] <name>

ARGUMENTS
  name string    Variable name (created as a declared variable when it does not exist)

FLAGS
  --server string         Server URL (defaults to config server)
  --project string        Project ID (default: the `defaultProject` setting)
  --env string            Environment ID (default: the `defaultEnvironment` setting)
  --type string           Declared value type (string | number | boolean | url; `none` clears it back to unspecified)
  --required              Declare the variable as required (`maruhi run` fails fast while it has no value)
  --optional              Declare the variable as not required
  --description string    Human-readable description (plaintext metadata visible to the server — never put secret values here)
  --clear-description     Clear the description (explicit — an empty --description value is rejected as a likely unset shell variable)
  --allow-high-entropy    Proceed without confirmation when the name or description contains a secret-like high-entropy string (fail-closed otherwise)

GLOBAL FLAGS
  --help, -h       Show help information
  --version, -v    Show version information

maruhi (㊙) stores your team's secrets encrypted end to end, keeps plaintext off every disk, and runs on Cloudflare Workers — either the hosted service at `my.maruhi.app` or your own account with a single `wrangler deploy`.

:::note
maruhi is in **private preview**. The hosted service is invite-only, and releases are pre-release tags. Expect changes; the [changelog and releases](https://github.com/maruhiapp/maruhi/releases) are the source of truth.
:::

## How maruhi works

- **End-to-end encrypted, zero knowledge.** Values are encrypted on your machine with WebCrypto and HPKE before they leave it. The server stores and relays ciphertext only.
- **Diskless.** `maruhi run -- <command>` decrypts in memory and injects values into the child process's environment. No `.env` files are written, ever.
- **Everything happens in the CLI.** The web dashboard is read-only and never receives a key or a plaintext value.
- **Nothing phones home.** The CLI, the dashboard, and this site send no telemetry and load no third-party scripts.
